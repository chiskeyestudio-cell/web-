Oliv.ia es una innovadora aplicación web diseñada para transformar la manera en que los usuarios descubren su próximo destino gastronómico. Desarrollada íntegramente con Streamlit, la plataforma combina el análisis avanzado de datos con potentes técnicas de Procesamiento de Lenguaje Natural (NLP) para filtrar el ruido de la red y ofrecer recomendaciones de restaurantes con un nivel de precisión personalizado.

La preparación

Oliv.ia + Samsung

A diferencia de los buscadores convencionales, Oliv.ia extrae valor directamente de la experiencia del cliente. Utilizando el extenso dataset de Yelp, el sistema procesa y analiza miles de reseñas reales para identificar patrones, sentimientos y preferencias específicas. Esto permite que el usuario no solo reciba una lista de locales, sino que pueda explorar visualmente el ecosistema de datos y obtener sugerencias que resuenan verdaderamente con sus gustos individuales.

Este desarrollo se presenta dentro del programa Samsung Innovation Campus, una iniciativa de formación de alto nivel en colaboración con la EOI (Escuela de Organización Industrial). El proyecto no solo demuestra el dominio de herramientas de análisis de datos, sino también la capacidad de convertir algoritmos complejos en una interfaz intuitiva y funcional para el usuario final.

El resultado

"La verdadera potencia de Oliv.ia reside en su capacidad para transformar el ruido de miles de reseñas en una recomendación única. Hemos logrado que la Inteligencia Artificial no solo procese texto, sino que entienda el deseo del comensal."
